# Sistema de diseño — propuesta
Identidad: verde agrícola, azul agua, superficies neutras. Conservar marca existente. Tokens iniciales: verde #247D62, azul #3D9EE0, fondo oscuro #101C23, superficie #1B2D35, texto claro #EDF5F3. Verificar contraste WCAG AA antes de aprobar.
## Layout
Sidebar colapsable, encabezado con contexto del predio, contenido modular. CAD con lienzo central, inspector contextual, barra de herramientas y métricas. En móvil, navegación y paneles adaptativos; modo campo guiado.
## Componentes
Botones, campos con unidad, tarjetas KPI, tablas, alertas, estados de carga/error/vacío, diálogos accesibles. Foco visible, teclado, etiquetas, no depender solo del color. Tipografía del sistema hasta definir marca.
## Datos
Formato es-CL, CLP, ha, m³, L/s; distinguir estimado, medido y simulado. No mostrar datos de demostración como reales. Prototipo pendiente de validación.
